Detailed Description

A small class to uniquely identify data stored in the datasources. The class contains 5 integer values : dataSourceId : Identifies the data source (see @medDataManager) patientId, studyId, seriesId identify the data within the source.

class medDataIndex

The integer value NOT_VALID is reserved to indicate unset or invalid data.

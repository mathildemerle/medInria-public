template<typename workspaceType >
bool medWorkspaceFactory::registerWorkspace ( bool  isActive = true)
inline

Registers a medAbstractWorkspaceLegacy type with the factory.

This method is templated with the workspaceType. This is a convience method. The constructor of the workspace - with a (QWidget *parent) signature - is used to create a function pointer to allocate memory. The workspace source code doesn't need to contain any such function itself.

nameHuman readable name (Potentially localised).
descriptionshort description (Potentially localised).

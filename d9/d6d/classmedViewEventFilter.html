Detailed Description

class medViewEventFilter This class can be added as an EventFilter on a medAbstractView. The class allows the retreival of the mouse clicks, including where the mouse was clicked in the coordinates defined by the view.

(see QObject::eventFilter & QObject::installEventFilter)

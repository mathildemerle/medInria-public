Detailed Description

Shows a warning dialog box telling the user there is no data in the DB.

Also writes in the settings whether the user wants to see this message again.

The setting is in the section "system", key: "showEmptyDbWarning".

The class doesn't check for this value before showing, this has to be done before trying to call this dialog.

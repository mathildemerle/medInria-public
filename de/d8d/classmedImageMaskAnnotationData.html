Detailed Description

Implementation of an overlay image to be used to mark voxels as inside, outside or unknown. Can be added to an image data as an annotation, in which case the size of this mask should match the size of the image.

The class contains a medAbstractImageData containing the actual mask data. This can be manipulated.

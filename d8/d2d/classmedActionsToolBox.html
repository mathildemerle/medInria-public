medActionsToolBox::medActionsToolBox ( QWidget *  parent = 0,
bool  ok = false 
)

This toolbox will show possible action buttons depending on the items that is currently selected in the file system or db browser.

Which actions are appropriate to which item is specified in the itemToActions map.

It consists of two widgets: one containing the buttons and another one with an explanatory label telling the user that an item must be selected. Both widgets' visibilities are set depending on the selection.

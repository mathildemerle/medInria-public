Detailed Description

template<typename volumeType, unsigned int imageDim>
class vtkItkConversion< volumeType, imageDim >

Template for itk to vtk converter. It inherits vtkItkConversionInterface. @detail It keep inside the ITK input image and provide for output an vtk port.
The hearth of this class is a itk::ImageToVTKImageFilter.

Detailed Description

Writes Contours onto disk with the custom .ctr/.bctr file extension. .bctr is a binary file composed of 3 main parts: 1 - A header of size 4 * 8 bytes 2 - A VTK mesh in binary 3 - a set of LabelDataSet readable as QByteStream

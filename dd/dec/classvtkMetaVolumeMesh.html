Detailed Description

Concrete implementation of vtkMetaDataSet for volumic mesh handling.

Author
Nicolas Toussaint

This class is a powerfull vtk Addon class that helps handling a vtkDataSet. Specific case of a volumic mesh, hendles, read and writes vtkUntructuredGrid object

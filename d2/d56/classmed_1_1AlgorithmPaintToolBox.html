Detailed Description

Segmentation toolbox to apply manual painting of pixels.

This toolbox has several named widgets which can be accessed in python pipelines:

"tabWidget" : QTabWidget
"Interpolate" : QPushButton
"Upper Threshold" : medDoubleParameter
"Lower Threshold" : medDoubleParameter
"Activate 3D mode" : QCheckBox
"saveButton" : QPushButton
"clearMaskButton" : QPushButton

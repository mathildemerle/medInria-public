Detailed Description

Factory for toolbox generation.

Any toolbox can be registered with this factory. A toolbox will be identified in the factory by a string that should be unique and identifies the type (in the dtk sense) of the toolbox. It should also have a readable name and description (localised are better).

Finally a list of category allows the toolbox to belong to categories such as:

  • diffusion
  • registration
  • filtering
  • ...

Developers can add their own categories, and use their own filters afterwards.

The details for each toolbox are stored in a struct of type medToolBoxDetails.

Registers a medToolBox type with the factory.

This method is templated with the toolboxType. This is a convience method. The constructor of the toolbox - with a (QWidget *parent) signature - is used to create a function pointer to allocate memory. The toolbox source code doesn't need to contain any such function itself.
